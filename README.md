# Kavyl（凯薇）

> 情绪记录 + 支持性 AI 助手的 iOS App。真记忆、人格稳定、安全克制的对话，加上情绪打卡、呼吸练习、晚安信等轻治愈功能。

Kavyl 面向 18–30 岁年轻人群：一个帮你记录情绪、看见自己规律的工具，配一位稳定、克制、会记住你的 AI 助手。

**Kavyl 不提供医疗或心理服务。** AI 助手不是真人，也不是治疗师。

---

## 功能

### AI 助手对话
- 治愈系角色人设，可选性别 / 名字 / 风格
- 文字聊天 + 语音输入 / 语音回复（情感化语音，识别全在本机）
- 由 Apple 端侧模型 / 私密云计算驱动，不接第三方 LLM
- 上下文感知：知道现在几点、叫得出你的名字，也会察觉手机快没电这类小事

### 真记忆系统
- 记住你的名字、家人、宠物、重要日子
- 主动回访："上周你提到的那件事，后来怎么样了？"
- 记忆内容你可见、可编辑、可删除

### 人格稳定
- 人设、语气、价值观稳定不变，更新不会改变既有的相处方式
- 任何人格调整需你确认

### 情绪记录
- 一键情绪打卡（emoji + 程度 + 一句话）
- 记录后助手会在同一张卡下留一句话，让"记录"变成"被回应"
- 情绪日历 / 趋势图 / 周报月报
- 情绪周报 + 角色写的信，可一键生成分享卡片

### 每天一件小事
- 每天一件很小、当下就能做完的事（出门走五分钟、拍一张让你平静的东西……）
- 不设连续打卡、不做惩罚、不给评价

### 轻治愈
- 呼吸练习：2–3 分钟动画引导（可计入健康「正念」数据）
- 晚安信：睡前一条定制温暖短讯，带角色口吻
- 按心情找歌（Apple Music）、为此刻配一首歌

### iOS 平台感
- 桌面小组件：角色"在线状态" / 今日一句暖心话
- 灵动岛 / 通知：角色主动问候，频控不骚扰
- Apple Watch：情绪快捷打卡 + 呼吸提醒

### 安全与克制
- 危机识别：检测到情绪风险时引导至当地心理援助热线（美国 988、英国/欧洲 116 123、日本 いのちの電話、韩国 1393 等）
- 反成瘾：长会话提醒、夜间免打扰、无连续打卡绑架、无广告
- 明示"AI 非真人"，并显示非医疗免责声明
- 匿名即可开始，数据可一键导出 / 删除，支持 Sign in with Apple

### 订阅
- 免费版可用完整人设（限每日消息量）
- 订阅解锁无限对话、情感化语音与更多自定义角色
