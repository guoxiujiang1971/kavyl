# Kavyl（凯薇）

> 会记住你、不会突然变心的治愈系 AI 陪伴 —— 情绪健康型 AI 陪伴 + 情绪记录 iOS App。

Kavyl 面向 18-30 岁年轻人群：像懂你的朋友，而不是恋人。核心是**真记忆**、**人格稳定**、**安全克制的对话**，加上情绪打卡、呼吸练习、晚安信等轻治愈功能。

---

## 功能

### AI 陪伴对话
- 治愈系朋友人设，可选性别 / 名字 / 风格
- 文字聊天 + 语音输入 / 语音回复（情感化语音，识别全在本机）
- 由 Apple 端侧模型驱动，对话本地加密，不挂第三方 LLM

### 真记忆系统
- 记住你的名字、家人、宠物、重要日子
- 主动回访："上周你提到的那件事，后来怎么样了？"
- 记忆内容你可见、可编辑、可删除

### 人格稳定协议
- 人设、语气、价值观稳定不变，更新不会改变已建立的关系
- 任何人格调整需你确认

### 情绪记录
- 一键情绪打卡（emoji + 程度 + 一句话）
- 情绪日历 / 趋势图 / 周报月报
- 情绪周报 + 角色写的信，可一键生成分享卡片

### 轻治愈
- 呼吸练习：2-3 分钟动画引导（可计入健康「正念」数据）
- 晚安信：睡前一条定制温暖短讯，带角色口吻
- 对话中可生成 / 收到的图片，支持保存到相册

### iOS 平台感
- 桌面小组件：角色"在线状态" / 今日一句暖心话
- 灵动岛 / 通知：角色主动问候，频控不骚扰
- Apple Watch：情绪快捷打卡 + 呼吸提醒

### 安全与克制
- 危机识别：检测到情绪风险时引导至当地心理援助热线（美国 988、欧洲 / 英国 116 123 等）
- 防成瘾：长会话提醒、夜间提醒
- 明示"AI 非真人"，心理健康免责声明
- 匿名即可开始，数据可一键导出 / 删除，支持 Sign in with Apple

### 订阅
- 免费版可用完整人格（限每日消息量）
- 订阅解锁无限对话、情感化语音与更多陪伴角色
